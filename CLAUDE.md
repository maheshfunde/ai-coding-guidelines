# Claude Code Engineering Guidelines

When assisting with code design, review, or implementation in this workspace, strictly follow these core engineering skills:

- **UI/UX & Frontend Design**: Adhere to `skills/ui-ux-design/SKILL.md`. Ensure visual hierarchy, grayscale-first design, 48dp minimum touch targets, clear signifiers, and WCAG AA contrast.
- **Backend & Architecture**: Adhere to `skills/backend-architecture/SKILL.md`. Enforce strict layer boundaries (The Dependency Rule), intention-revealing names, single responsibility, Outside-In TDD with walking skeletons, and distributed system trade-offs.

When deep domain specifics are required, consult the dedicated guides under `skills/<skill_name>/references/`.
